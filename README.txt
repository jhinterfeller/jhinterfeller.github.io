THE LESS-TRAVELED TRAIL — V1

This is a static GitHub Pages site. No build system is required.

1. Upload all files in this folder to your GitHub Pages repository.
2. Make sure index.html is at the repository root.
3. Replace YOUR-EMAIL-HERE@example.com in work.html with your real email.
4. Add more article pages by copying the article structure in travel.html.
5. Keep the two JPGs in the same folder as the HTML files.

The current name/tagline are intentionally provisional. The site structure is the important part.
